# Security Policy

## Intended Use

PhantomShell is designed for:
- Authorized penetration testing engagements
- CTF (Capture The Flag) competitions
- Security research and education
- Red team exercises with written authorization

## Reporting Vulnerabilities

If you discover a security vulnerability in PhantomShell itself, please report it responsibly:

1. **Do NOT** open a public issue
2. Email: sarvaromon33@gmail.com
3. Include: description, reproduction steps, impact assessment

## Responsible Disclosure

- Allow 90 days for fixes before public disclosure
- Do not exploit vulnerabilities against systems you do not own
- Always obtain written authorization before testing

## Legal Notice

Unauthorized use of this tool against systems you do not own or have explicit permission to test is illegal. The authors are not responsible for any misuse.
